# Logo Captivia — PROVISOIRE

`captivia-mark.svg` est un logo provisoire (feuille stylisée sur fond vert de la charte, `#0aa678`) créé pour débloquer la PWA (W4-06).
Il doit être remplacé par le logo maître 1024×1024 fourni par le designer (décision D-15, voir `docs/PLAN-PRODUCTION.md`), puis les icônes dérivées
(`src/app/icon.png`, `src/app/apple-icon.png`, `public/icons/*`, `public/badge.png`) doivent être régénérées.
